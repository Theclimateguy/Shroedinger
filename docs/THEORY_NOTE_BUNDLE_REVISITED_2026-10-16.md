# Формализм gen1 на новом знании: расслоение, локальный перенос энергии, кривизна
## Статус: ЗАПИСКА (не протокол), 2026-10-16. Ничего не считалось. Знаки и приоры записаны до расчётов.

Повод: Phase 39 (ENERGY_LOCALITY_AND_STATIONARY_ENERGY) дала физическое прочтение
сопряжённости: поток энергии Π_ℓ (огрубление по Жермано) сосредоточен там, где
активность соседних полос совмещена в данный момент (взаимодействие b3 > 0 в
лог-координатах, транзиентно — исчезает при сдвиге на 5 суток), а стационарный
шаблон = доля энергии полосы, удерживаемая стационарными вихрями. Вопрос автора:
вернуться к формализму gen1 (гильбертово расслоение по (x, μ), связность по масштабу,
Λ = Tr(Fρ), игрушечная u(2)-модель) и спросить, что из первых гипотез можно
переспросить, и есть ли кривизна, связанная с локальным переносом энергии между
масштабами.

Краткий ответ, который развёрнут ниже:

1. Да, есть — но на первом уровне это **тождество**, а не гипотеза: некоммутативность
   огрубления и нелинейной динамики есть подсеточная сила ∇·τ_ℓ, а её свёртка с
   состоянием — локальный поток Π_ℓ. Формула gen1 Λ = Tr(Fρ) с «синусоидальным
   законом» переписывается в точное гидродинамическое тождество
   Π_ℓ = −k δ̄ − k c σ̄ cos 2Δθ (раздел 3). Это переименование, не открытие.
2. Содержание появляется на втором уровне — в **геометрии выравнивания**: в
   бездивергентном 2D-потоке безпамятная (мгновенно-градиентная, Кларк) модель даёт
   Π ≡ 0. Весь наблюдаемый перенос энергии — отклонение директора подсеточного
   напряжения от кинематического положения, то есть ровно «поворот образующих между
   слоями» gen1 (sin φ), и он может прийти только из истории (памяти A05) или из
   структуры мельче грубого градиента. В атмосфере (850 гПа, δ̄ ≠ 0) безпамятная
   часть есть и она — дивергентная: Π^C ∝ −δ̄(3σ̄² + ω̄² + δ̄²). Это «вакуумная» часть
   gen1 (Λ_diag), тогда как бездивергентная «когерентная» часть требует памяти.
3. Настоящая, нетавтологическая кривизна есть у связности «переноси по времени
   скоростью своего масштаба»: горизонтальный подъём ∂_t зависит от ℓ, и
   [D_t^{(ℓ)}, ∂_ℓ] = −(∂_ℓ ū_ℓ)·∇ ≠ 0. Её голономия — угол, на который мелкая
   структура видит поворот оси деформации грубого поля из-за того, что её несёт не та
   скорость. Это поправка к критерию Lapeyre–Klein–Hua и единственное место, где
   «геометрия» может дать то, чего нет у Π и спектра. Проверяема, нуль есть.

## 3. Словарь: расслоение gen1 ↔ фильтрованная гидродинамика

### 3.1 База, слой, перенос

- База: (t, x, ℓ); x на сфере, ℓ — ширина гауссова фильтра (сглаживатель Phase 34).
  Октавы — не прямая сумма подпространств одного L², а локальные слои над (x, ℓ):
  это и есть «гильбертово расслоение как октавы» в операциональном смысле.
- Слой V_{x,ℓ}: градиент огрублённой скорости A_ℓ = ∇ū_ℓ, вещественная 2×2.
  Разложение A = S + Ω + (δ/2) I:
  σ_n = ∂_x ū − ∂_y v̄, σ_s = ∂_y ū + ∂_x v̄, ω = ∂_x v̄ − ∂_y ū, δ = ∂_x ū + ∂_y v̄;
  S = ½[[σ_n, σ_s], [σ_s, −σ_n]], σ := (σ_n² + σ_s²)^{1/2}, θ_S = ½ atan2(σ_s, σ_n)
  (ось растяжения). Бесследовая часть лежит в sl(2, R); её форма Киллинга
  tr(A_0²) = (σ² − ω²)/2 — **параметр Окубо–Вайсса**. Деформационные точки —
  «пространственноподобные», вихревые — «времениподобные». Алгебра игрушечной
  модели su(2) (компактная) заменяется на sl(2, R) ≅ su(1,1) (некомпактная):
  поворот оси деформации — компактная подгруппа SO(2) (угол 2θ_S), переход
  деформация ↔ вращение — «буст».
- Перенос по ℓ: фильтрация, линейна, коммутирует с переносом по x (однородный
  фильтр). Сама по себе кривизны не даёт (одно направление).
- Перенос по t: динамика. Некоммутативность с фильтрацией:
  G_ℓ[N(u)] − N(G_ℓ u) = −∇·τ_ℓ, τ_ij = G_ℓ(u_i u_j) − ū_i ū_j.
  Это в точности Δ^mem gen1 (аксиома совместности), только он не мал: в инерционном
  интервале это и есть каскад. Энергетическая проекция:
  ū·(∇·τ) = ∇·(ū τ) + Π_ℓ, Π_ℓ := −τ_ij ∂_j ū_i.

### 3.2 Матрица плотности слоя и Λ ↔ Π (точное тождество)

Подсеточное напряжение τ_ℓ симметрично и положительно полуопределено. Поэтому
ρ_ℓ := τ_ℓ / tr τ_ℓ — честная 2×2 матрица плотности (вещественная, ρ ⪰ 0, Tr ρ = 1):

  ρ_ℓ = ½ (I + c (cos 2θ_τ σ_3 + sin 2θ_τ σ_1)),
  k := ½ tr τ (подсеточная энергия), c := |τ^d| / tr τ ∈ [0, 1] (анизотропия),
  θ_τ = ½ atan2(2τ_xy, τ_xx − τ_yy) (директор напряжения).

Вектор Блоха ρ — анизотропия и директор напряжения; ρ = I/2 — изотропное
напряжение. Тогда

  **Π_ℓ = −tr τ · Tr(ρ_ℓ sym A_ℓ) = −k δ̄ − k c σ̄ cos 2(θ_τ − θ_S).**        (3.1)

Сопоставление с gen1 (формулы eq:Lambdamatter_def, eq:sinlaw, eq:Lambda_split):

| gen1 | гидродинамика | замечание |
|---|---|---|
| Λ = Tr(F ρ) | Π = −tr τ · Tr(ρ_τ sym A) | образующая F ↔ градиент грубого поля; состояние ρ ↔ нормированное подсеточное напряжение |
| Λ_diag (вакуумная часть, не зависит от когерентности) | −k δ̄ | изотропная часть напряжения × дивергенция; в бездивергентном потоке 0 (поглощается давлением) |
| Λ_coh ∝ ⟨σ_x⟩ sin φ | −k c σ̄ cos 2Δθ | ⟨σ_x⟩ ↔ анизотропия c; φ ↔ 2Δθ, угол между директорами соседних масштабов |
| ρ ∝ I ⇒ источник зависит только от следа F | c = 0 ⇒ Π = −k δ̄ | ровно замечание gen1 rem:nontrivial_source |
| «поворот образующих между слоями» | поворот директора напряжения относительно оси деформации | измеримо в ERA5 и в игрушке |
| вертикальный поток J^μ (аксиома баланса) | Π_ℓ | бюджет энергии полосы: ∂_t E_k + ∇·J_k = Π_{k−1} − Π_k + F − D |
| GKSL, декогеренция | возврат к изотропии (Rotta): c → 0 | скорость возврата — измеримый параметр, не постулат |

Численная проверка (2026-10-16, случайные гладкие поля на периодической сетке,
гауссов фильтр, формула потока как в Phase 39): (3.1) выполняется с относительной
ошибкой 1e-16 с дивергенцией и без; (3.2) — ошибка 1e-16; в бездивергентном поле
Π^C/Π ~ 1e-22 и директор τ^C ровно под 45° к оси деформации.

Это тождество, а не результат: оно лишь говорит, что форма Tr(Fρ) была правильной,
а операционализация в A15 (ридж-карты между коэффициентами полос, прокси потока
⟨|k|E(k)⟩) — нет. Вернуть «Λ_b ~ Π_b» как проверку нельзя: проверять нечего.

### 3.3 Безпамятный нуль (модель Кларка) и почему перенос — «когерентная» часть

Если подсеточное напряжение — мгновенная функция грубого градиента
(модель Кларка / градиентная, ведущий член многомасштабного градиентного
разложения): τ^C = C ℓ² A Aᵀ. Прямое вычисление в 2D:

  A Aᵀ = ((σ² + ω² + δ²)/4) I + [Ω, S] + δ S.

Член [Ω, S] симметричен, бесследов и **ортогонален S** (tr([Ω,S] S) = 0): директор
τ^C повёрнут на 45° к оси деформации (2Δθ = ±90°, знак по знаку ω). Отсюда

  **Π^C = −(C ℓ²/4) δ̄ (3σ̄² + ω̄² + δ̄²),   Π^C ≡ 0 при δ̄ = 0.**            (3.2)

Следствия:

- В бездивергентном 2D-потоке безпамятная модель переносит энергию **ровно ноль**.
  Весь наблюдаемый Π — отклонение директора τ от кинематического положения 45°,
  то есть Π ∝ sin(2(θ_τ − θ^C)) · k c σ̄: буквально синусоидальный закон gen1,
  где «φ = 0 — коммутирующий режим — источник исчезает» ↔ «директор напряжения в
  кинематическом положении — переноса нет». Поворот может прийти только из
  лагранжевой истории напряжения (память A05 в точной форме) или из структуры
  мельче грубого градиента (следующие порядки разложения).
- В атмосфере на 850 гПа δ̄ ≠ 0, и безпамятная часть есть — она дивергентная:
  сходимость (δ̄ < 0) даёт прямой перенос, пропорциональный энергии градиента.
  Это ровно «вакуумная» часть Λ_diag, а бездивергентная — «когерентная».
- Для потока энстрофии Z_ℓ = −τ^ω·∇ω̄, τ^ω = G(uω) − ū ω̄ (носитель P — вихрь!)
  безпамятный член не нулевой:
  Z^C = −C ℓ² [∇ω̄·S̄·∇ω̄ + (δ̄/2)|∇ω̄|²] — фронтогенетического типа (Петтерсен):
  прямой каскад энстрофии ⇔ градиент вихря вдоль сжимающей оси. Это критерий
  Lapeyre–Klein–Hua (LKH): выравнивание ∇ω̄ с осью деформации управляется
  r = (ω̄ + 2 D_t θ_S)/σ̄ вдоль траектории грубого поля; |r| < 1 — выравнивание,
  |r| > 1 — вращение, переноса мало.

Так факты F4–F5 получают кандидат-объяснение: на 400 км чистый прямой перенос
энергии в 95 % окон — потому что на 850 гПа есть дивергентная (конвективная,
агеострофическая, масштабно-локальная) часть Π^C; «CAPE понижает P сверх спектра»
— потому что там перенос вакуумный, а не когерентный; P сверх спектра должен идти
за когерентной частью. Это гипотеза G5 ниже, не вывод.

## 4. Есть ли кривизна, связанная с локальным переносом энергии?

### 4.1 Уровень 0 — тождество

F_{tℓ} ↔ подсеточная сила; Tr(Fρ) ↔ Π. Кривизна отлична от нуля там и тогда, где
активен каскад; локальность Π по x (F4) = локальность кривизны. Ответ «да», но
это не даёт ничего сверх Π.

### 4.2 Уровень 1 — геометрия выравнивания (есть prior art в 2D DNS)

Разложение (3.1): Π = амплитуда (k σ̄) × анизотропия (c) × выравнивание (cos 2Δθ)
+ вакуумная часть (−k δ̄). Огибающие P видят только амплитуду. Сверхмультипликативность
b3 (F4) должна сидеть в c · cos 2Δθ. Нуль без памяти — (3.2). Отклонение от него —
«память/история»: измеримо как лаг между S̄ вдоль траектории и c, θ_τ.

### 4.3 Уровень 2 — кривизна дифференциального сноса (нетавтологическая)

Связность «переноси по времени скоростью своего масштаба»:
D_t^{(ℓ)} := ∂_t + ū_ℓ·∇ (горизонтальный подъём ∂_t зависит от ℓ). Тогда

  **[D_t^{(ℓ)}, ∂_ℓ] = −(∂_ℓ ū_ℓ)·∇ ≠ 0,**                                (4.1)

и на сечениях θ_S (U(1)-расслоение директоров, mod π) кривизна
F_{tℓ} = (∂_ℓ ū_ℓ)·∇θ_S, а голономия по петле (dt, dℓ) — угол, на который мелкая
структура (масштаб ℓ′ < ℓ) видит поворот оси деформации грубого поля из-за того,
что её несёт ū_{ℓ′} = ū_ℓ + u_band, а не ū_ℓ. Проинтегрированная по полосе:

  ∫_{ℓ′}^{ℓ} F_{tℓ} dℓ = u_band · ∇θ_S,   u_band := ū_{ℓ′} − ū_ℓ.

Безразмерно: Sw := |u_band·∇θ_S| / σ̄ (число сноса). Это поправка к критерию LKH
для структуры масштаба ℓ′ в деформации масштаба ℓ:

  r_{ℓ′ℓ} = (ω̄_ℓ + 2 [D_t^{(ℓ)} θ_S + u_band·∇θ_S]) / σ̄_ℓ.                (4.2)

Физика: выравнивание требует времени ~ 1/σ̄; если за это время сносом структуру
уносит через область, где ось деформации повёрнута, выравнивания нет и переноса
нет. Галилеева инвариантность соблюдена (u_band — разность скоростей; Π, τ, θ_S
инвариантны). Это единственный объект в записке, который не сводится ни к Π, ни к
спектру, и у которого есть нуль: сдвиг на 5 суток (убирает транзиентную часть,
сохраняет шаблон, как в Phase 39) и зеркальные/фазовые суррогаты (сохраняют
спектр, рвут связь u_band с ∇θ_S).

### 4.4 Топологический вариант (низкий приор, только запись)

Поле директоров θ_S (нематическое) имеет дефекты в нулях |S̄| с полуцелыми
зарядами; при изменении ℓ дефекты рождаются/уничтожаются парами. «Кривизна» U(1)
чистой калибровки сосредоточена в дефектах. Связь с переносом неочевидна;
не предлагается к проверке первым.

## 6. Игрушечная модель v2

Старая u(2)-игрушка (T-серия) абстрактна: алгебра su(2), поворот φ между слоями,
источник Λ ∝ ⟨σ_x⟩ sin φ. Результаты G (синусоидальный закон), K2 (корреляции
кривизны), H/I/J (регуляризация, непрерывный предел, Берри) верны в своём классе
и совместимы с прочтением раздела 3, но новой информации не несут — оставить
приложением. Новая игрушка должна быть мостом между формализмом и данными.

### 6.1 Ядро

`clean_experiments/explore_physics_toy2d.py` (2D вихрь / SQG, псевдоспектр,
интегрирующий множитель, две полосы вынуждения). Добавить:

- (a) стационарный шаблон: стационарная составляющая вынуждения f_s(x, y) с долей s
  и/или топография h(x, y) в q = ω + h — для воспроизведения F3 (доля шаблона ↔
  доля стационарной энергии) под контролем;
- (b) сдвиговый фоновый поток U(y) = U_0 sin y (струя) — управляет сносом Sw
  независимо от σ̄ (однородный поток галилеево тривиален, нужен именно сдвиг);
- (c) опционально, следующим шагом: мелкая вода (дивергентная часть, «вакуумный»
  член −k δ̄) — тяжелее, отдельно.

### 6.2 Инструментарий расслоения (функция `bundle_fields(u, v, ℓ)`)

По полосе: A_ℓ (σ_n, σ_s, ω, δ), OW, θ_S; τ_ℓ (3 компоненты), k, c, θ_τ, ρ_ℓ;
Π, Π_iso = −k δ̄, Π_dev; Δθ; τ^C и остаток τ − τ^C; Z_ℓ и Z^C; u_band; Sw;
D_t θ_S и r по (4.2) вдоль траекторий грубого поля (частицы, адвекция ū_ℓ);
голономия F_{tℓ} по плакетке; замыкание бюджета энергии полосы (аксиома баланса
gen1 как контроль).

## 7. Prior art (по памяти; проверить до любой формулировки претензии на новизну)

## 10. Дополнение (2026-10-16, вечер): первые результаты игрушки v2

`clean_experiments/explore_toy_v2_bundle.py`, отчёт
